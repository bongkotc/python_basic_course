# python_basic_course
Python Basic Course

  ```bash
  python -m venv .venv
  .venv\Scripts\activate

📥ส่วนที่ 1: เตรียมตัวและพื้นฐานแรกสุด (EP 1 - EP 2)
EP 1: แนะนำภาษา Python & การติดตั้งเครื่องมือ

เนื้อหา: Python คืออะไร นำไปใช้อะไรได้บ้าง และสอนการติดตั้ง Python ร่วมกับ Visual Studio Code (VS Code) หรือ Thonny พร้อมรันโค้ดแสดงผลคำว่า print("Hello World") ตัวแรก และการเขียนคอมเมนต์ (#)

EP 2: ตัวแปร (Variables) & ชนิดข้อมูลพื้นฐาน (Data Types)

เนื้อหา: วิธีสร้างตัวแปรเพื่อเก็บข้อมูล ชนิดข้อมูลพื้นฐานที่ควรรู้ เช่น ข้อความ (str), ตัวเลขเต็ม (int), ทศนิยม (float), ค่าความจริง (bool) และการรับค่าจากผู้ใช้ด้วย input()

⚙️ ส่วนที่ 2: การควบคุมทิศทางโปรแกรม (EP 3 - EP 4)
EP 3: ตัวดำเนินการและการตัดสินใจเงื่อนไข (Operators & if-elif-else)

เนื้อหา: ตัวดำเนินการทางคณิตศาสตร์ (+, -, *, /) และตัวดำเนินการเปรียบเทียบ (>, <, ==) พร้อมคำสั่งเช็คเงื่อนไขในการทำโปรแกรมเลือกทำอย่างใดอย่างหนึ่ง

EP 4: การวนซ้ำ (Loops: for และ while)

เนื้อหา: การสั่งให้โปรแกรมทำงานซ้ำ ๆ ด้วย while loop (วนซ้ำตามเงื่อนไข) และ for loop (วนซ้ำตามจำนวนรอบหรือตามข้อมูลในลิสต์) พร้อมคำสั่งควบคุม เช่น break หรือ continue

📦 ส่วนที่ 3: โครงสร้างข้อมูลที่ใช้เก็บคอลเลกชัน (EP 5 - EP 7)
EP 5: ข้อมูลแบบโครงสร้างลิสต์ (Lists)

เนื้อหา: การเก็บข้อมูลเป็นชุดในตัวแปรเดียว การเข้าถึงข้อมูลด้วยตำแหน่ง (Index & Slice) และฟังก์ชันจัดการ List เช่น .append(), .remove(), .sort()

EP 6: ทูเพิล และ เซต (Tuples & Sets)

เนื้อหา: ความแตกต่างของ Tuple (ลิสต์ที่แก้ไขค่าไม่ได้) และ Set (กลุ่มข้อมูลที่ไม่ซ้ำกันและไม่เรียงลำดับ) เพื่อเลือกใช้งานให้ถูกรูปแบบ

EP 7: ดิกชันนารี (Dictionaries - Key & Value)

เนื้อหา: การเก็บข้อมูลแบบจับคู่กุญแจและข้อมูล (Key-Value Pairs) ซึ่งสำคัญมากในการจัดการข้อมูลที่มีโครงสร้าง เช่น ประวัตินักเรียนที่มี ชื่อ อายุ และเกรด

🧩 ส่วนที่ 4: การจัดระเบียบโค้ดและการประยุกต์ใช้งาน (EP 8 - EP 10+)
EP 8: การสร้างฟังก์ชันใช้งานเอง (Functions)

เนื้อหา: การสร้างบล็อกโค้ดเพื่อนำกลับมาใช้ซ้ำด้วยคำสั่ง def การส่งค่าพารามิเตอร์ (Arguments) และการส่งค่ากลับด้วย return

EP 9: การจัดการข้อผิดพลาด (Exception Handling: try-except)

เนื้อหา: วิธีดักจับ Error เพื่อไม่ให้โปรแกรมค้างหรือหลุดเมื่อเกิดข้อผิดพลาด เช่น ผู้ใช้กรอกข้อความแทนที่จะกรอกตัวเลขในระบบคำนวณ

EP 10: การนำเข้าโมดูล และไลบรารีพื้นฐาน (Modules & Libraries)

เนื้อหา: การใช้คำสั่ง import เพื่อดึงโมดูลติดตัวของ Python มาช่วยทำงาน เช่น โมดูลคณิตศาสตร์ math, โมดูลเวลา time หรือโมดูลวาดรูปสร้างกราฟพื้นฐาน

EP 11 (แถม): การอ่าน-เขียนไฟล์พื้นฐาน (File Handling)

เนื้อหา: สอนการเปิด อ่าน และเขียนข้อมูลลงไฟล์ข้อความ (.txt) ด้วยคำสั่ง with open()
